# meu-primeiro-pr

Projeto de exemplo para praticar o fluxo de Pull Request com GitHub.

## Sobre

Este repositório foi criado para aprender a:

- Criar branches
- Fazer commits
- Abrir Pull Requests

## Como usar

Clone o repositório e explore os arquivos.

## Contibuting

Contribuições são bem-vindas! Sinta-se livre para abrir issues e pull requests.
